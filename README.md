# El Sindicato del Hacking

Web estática publicada con GitHub Pages desde `main:/`.

- Dominio canónico: https://sindicatodelhacking.com
- Entrada: `index.html`
- Recursos: `assets/`
- El archivo `CNAME` mantiene el dominio asociado al sitio.
- El DNS del dominio se gestiona en Cloudflare y apunta a GitHub Pages.

Los cambios publicados en `main` actualizan el sitio.
